# Python parity status — 2026-08-29

Phase 5 of the contract (`03-process.yaml`) is "behavior comparison against
Python as an executable spec". This records where the Rust port now stands
against the Python launcher (`src/rdp_tui/`), whose intended user-visible
behavior is the parity target — not its implementation defects.

The one implementation of field parsing/formatting lives in `model::fields`
(manifest `shared_logic: [tui, cli]`), so the CLI `set` command and the TUI
form offer exactly the same fields with no `tui`↔`cli` edge. Out-of-range
values (e.g. a non-{100,140,180} scale) are rejected by the store rather than
written as an unreadable profile.

## Beyond parity

- **Connection history** — every finished session is appended to the reserved
  `$XDG_STATE_HOME/rdp-tui/history.toml` (a locked, schema-versioned config
  document; profile id + outcome only, never a secret). Surfaced by
  `rdp-tui history [<id>]`, the TUI `h` overlay, and a "Last session" line in the
  status overlay — all via one shared `HistoryEntry::summarize`.

## Intentional differences

- **Deep-test** is a Rust addition beyond Python: FreeRDP auth-only credential
  verification, delivered via an inherited memfd argument descriptor (never in
  argv/env). Available in both frontends.
- **CLI-only, by design:** the diagnostic/one-shot commands that do not fit an
  interactive loop — `inspect`, `validate`, `migrate python`, `config-paths`,
  `info` — and the changed-certificate recovery flow (`certificate
  trust/backups/restore`). Certificate *policy* is editable in the TUI form.

## Deferred (by decision)

- **Python `--with-secrets` migration.** The user is the sole user and the
  migration path would run at most once; `migrate python` moves profiles but
  intentionally does not carry secrets over. Passwords are re-entered with `p` /
  `credential set`.

## Contract conformance (phase 5 + deep-test)

`tests/architecture_contract.rs` validates the module graph, forbidden edges,
stable-id resolution, binding types, and source-archive hash on every build.
All 13 invariants (INV-1…13) and 18 anti-patterns (AP-1…18) hold. The
deep-test **one-time per-profile warning** (`DEC-deep-test-framing`,
`diagnostic_tiers.deep_test.warning`) is implemented and gated before any
network work. Remaining test-matrix rows that are mechanism-only (no scripted
test) are the ones needing a PTY or a real process-kill harness — terminal
raw-mode restoration end-to-end and the SIGKILL tunnel-survival pair; their
core latches (`TerminalGuard` restore-once, `LaunchMode` PDEATHSIG policy) are
unit-tested.

## Verification

`make test`, `make lint` (clippy pedantic, `-D warnings`), `make format-check`,
and `git diff --check` are green on every commit. FreeRDP behavior (SDL
fullscreen sizing, askpass delivery, auth-only classification) was validated
against real hosts (Compono, Anima) during development.
