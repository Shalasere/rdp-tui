# Rust cleanup implementation — 2026-09-15

This pass implemented the post-review cleanup plan without replacing the
existing Python launcher or deleting historical audit documents.

## Completed

- Certificate-change handling now persists the exact fingerprint emitted by
  the supervised attempt. CLI and TUI approval require that exact value, verify
  that the endpoint and old pin are unchanged, archive the old pin privately,
  and require a fresh TOFU connection.
- RD Gateway profiles carry an independent username, domain, and credential.
  FreeRDP 3 uses compound `/gateway:` syntax; FreeRDP 2 uses its legacy gateway
  switches. Migration defaults an unspecified gateway port to 443.
- Deep-test is fail-closed for unknown output, has a 30-second timeout, uses
  sealed argument memory, and launches as an owned one-shot child. A successful
  banner is accepted only with a successful exit; the known auth-only
  cancellation remains an explicit success signal.
- Session records, internal logs, lock files, and fallback runtime directories
  are owner-only. Internal FreeRDP monitoring logs are removed on every return
  path, tunnel cleanup runs after both success and failure, and all readers use
  the same UID-scoped runtime fallback as the supervisor.
- Credential replacement, clearing, profile deletion, route changes, cloning,
  and import updates use shared workflows. Profile replacement returns the old
  value from the same locked transaction before unreferenced secrets are
  removed. Clones drop both credential slots.
- Imports accept Remmina, RDP, native TOML, and legacy JSON, merge a batch in
  one lock transaction, exclude credentials, and report added, updated,
  skipped, and per-file failed counts.
- TCP attempts share one deadline instead of multiplying the timeout by every
  resolved address. TUI reachability and deep tests run on dedicated workers so
  the event loop remains responsive.
- XDG path policy and state-changing workflows are centralized. TUI rendering
  is separated into `src/tui/app/view.rs`.

## Validation

The completion gate is:

```sh
make test
make lint
make format-check
git diff --check
```

The architecture-contract graph and gateway/certificate/import/lifecycle
regressions are part of that gate. Real-host RDP authentication and certificate
replacement remain manual integration checks because the repository test suite
does not contain target credentials or a disposable RDP server.
